# Button Hair Clip — Sixteen-Material Interactive Viewer

Open this folder through a local web server and load `index.html`. Keep `model-viewer.min.js` and the `models` folder beside the page.

The viewer opens with a combined overview of all sixteen material studies. Use the material menu to load an individual variant, drag to rotate, scroll or pinch to zoom, reset the camera, or enable automatic rotation.

The interface is entirely in English and is designed for embedding in the Project 1 modal at a 62.5% frame ratio. The source Chinese viewer remains preserved as `HairClip_Web_v01`.
